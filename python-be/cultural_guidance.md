# 🌍 Cultural Translation Guidance for All Languages

Use this data to populate your Language-Specific Settings. Each entry has "TO" and "FROM" guidance relative to Danish.

---

## 🇺🇸 **English (United States) - en-US**

**When Translating TO English (United States):**
Transform Danish directness into American customer-service friendliness. Add "please" and "thank you" more frequently. Use solution-focused language ("Here's what we can do..."). Americans expect helpful, accessible communication even in government contexts.

**When Translating FROM English (United States):**
Tone down excessive enthusiasm and marketing-speak. Convert American politeness into Danish efficiency while keeping helpfulness. Remove unnecessary pleasantries but maintain professional courtesy.

---

## 🇳🇱 **Dutch (Netherlands) - nl-NL**

**When Translating TO Dutch (Netherlands):**
Both cultures value directness - minimal adaptation needed. Use "u" for formal address in official contexts. Dutch appreciates even more directness than Danish. Be practical and straightforward.

**When Translating FROM Dutch (Netherlands):**
Dutch directness translates perfectly to Danish. Maintain practical, no-nonsense communication style. Very little cultural adaptation required between these similar cultures.

---

## 🇪🇬 **Arabic (Egypt) - ar-EG**

**When Translating TO Arabic (Egypt):**
Major formality upgrade required. Add "السلام عليكم" greetings, use "حضرتك" for respectful address. Transform Danish brevity into elaborate Arabic courtesy. Include religious/cultural pleasantries. Show proper respect and honor.

**When Translating FROM Arabic (Egypt):**
Simplify elaborate courtesy phrases. Convert formal honorifics into appropriate Danish politeness. Remove excessive formalities while maintaining respect. Distill meaning from high-context communication.

## 📝 **How to Use This Data:**

1. Go to Settings → Language Context tab
2. Select each language
3. Copy the "TO" guidance into the first field
4. Copy the "FROM" guidance into the second field
5. Save each language context

This will give your translation system comprehensive cultural intelligence for all supported languages!
